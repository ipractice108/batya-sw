### Ключевой Мессендж

> "Я — пожарный из России. Моя работа — спасать жизни. А мои тренировки — это не шоу, а подготовка к реальным вызовам. Отжимания на топорах — символ того, что даже в самых острых ситуациях мы остаёмся на ногах."

## 🚀 Запуск Проекта

### Простой способ

1. Откройте `index.html` в браузере
2. Или используйте Live Server для разработки

### С локальным сервером

```bash
# Python 3
python -m http.server 8000

# Node.js (с http-server)
npx http-server

# PHP
php -S localhost:8000
```

Откройте браузер: `http://localhost:8000`

## 🎨 Customization

### Изменение цветов

Отредактируйте CSS переменные в `styles.css`:

```css
:root {
    --color-primary: #FF4500;
    --color-secondary: #DC143C;
    --color-accent: #FFD700;
}
```

### Добавление новых языков

1. Добавьте атрибуты `data-{lang}` к элементам в HTML
2. Обновите функцию `updateLanguage()` в `script.js`
